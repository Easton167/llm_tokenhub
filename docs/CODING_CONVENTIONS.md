# 编码与文案约定

| 项目 | 内容 |
| --- | --- |
| 适用范围 | 本仓库全部源码、文档、前端文案 |
| 配套规则 | `.cursor/rules/utf8-encoding.mdc`（Cursor Agent 始终生效） |

---

## 1. 文件编码

- 统一使用 **UTF-8，无 BOM**。
- 编辑器、终端、脚本读写均按 UTF-8；不要用系统默认 ANSI/GBK 保存源文件。
- Git 与 CI 按文本文件处理；勿引入混合编码提交。

## 2. 中文内容

- 前端界面文案、后端注释/日志说明、`docs/` 文档中的中文均为一等公民，修改时不得破坏原有汉字。
- 禁止出现因编码错误导致的 `??`、`å¯ç¨` 类乱码进入主干。
- 乘号等符号使用 Unicode（如 `×` / U+00D7），不要写入单字节 `0xD7` 破坏 UTF-8。

## 3. 安全改法

1. 优先小范围替换，避免整文件错误重编码。
2. 必须整文件重写时：UTF-8 读入 → 修改 → UTF-8 写出，并抽查中文关键字。
3. 若文件已大量损坏为 `??`：停止补丁，从完好版本恢复后再改。

## 4. 自检（改完含中文文件后）

- 文件可用严格 UTF-8 解码（无 `UnicodeDecodeError`）。
- 相关页面/文档中的中文标题、状态文案、按钮文字仍可读，而非 `??`。
