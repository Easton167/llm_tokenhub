## 关键规则

- 前台用户 REST 使用 JWT；模型调用 `/v1/*` 使用平台 API Key（与 JWT 分离）。
- 前台仅暴露用户自身数据；组织数据见二期。
- 模型列表与对话可选模型均受角色授权约束。
- **会话历史**：会话标题与对话正文持久化到服务端（按用户隔离）；前台同会话发送时携带完整历史消息以实现多轮上下文。旧版 localStorage 数据会在首次登录时自动迁移一次。
- **知识库问答**（规划中）：知识库挂载配置与引用来源随会话持久化；RAG 检索编排在前台服务侧完成，不改动对外 `/v1/chat/completions` 协议；挂载知识库需校验归属。
- **赠送余额透明化**：钱包页需明确标注赠送余额「不可退款 / 不可提现」及到期时间；余额不足提示按**总可用额**（赠送 + 充值）判断，避免用户看到充值余额为 0 就以为不能用。
