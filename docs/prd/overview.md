# 产品概述

> 返回 [PRD 索引](../PRD.md)

---

## 背景

随着大模型（LLM）厂商（OpenAI、Anthropic、Google、阿里通义、字节豆包、DeepSeek 等）数量与模型版本快速增长，企业与开发者在实际落地中普遍面临以下痛点：

- **接入碎片化**：各厂商鉴权方式、请求/响应协议、流式格式、错误码、限流策略各不相同，重复对接成本高。
- **多账号管理混乱**：多个厂商、多个 Key、多套额度，缺乏统一管理与监控。
- **缺乏统一计费与成本可视**：各厂商计费维度（输入/输出/缓存 Token、按次）不一致，难以统一核算与分摊。
- **稳定性与容灾不足**：单一厂商或单一 Key 故障即导致业务中断，缺少自动故障转移。
- **权限与合规难管控**：团队/组织内难以做到「谁能用哪些模型、用多少额度」的精细化管控。

## 产品定位

一个**统一的大模型聚合网关（LLM Gateway）/ AI 中台**：用户只需**一个 API Key + 一个统一 Base URL**，即可调用所有已接入厂商的模型。平台屏蔽底层差异，统一负责**协议转换、智能路由、鉴权、计费、用量统计与权限管控**。

对外接口**兼容 OpenAI API 规范**，使存量用户可「零改造 / 极低改造」迁移。

## 产品目标

| 维度 | 目标 |
| --- | --- |
| 易用性 | 一个 Key、一个 Base URL 调用全部模型；OpenAI 兼容，迁移成本接近于零 |
| 稳定性 | 多 Key/多渠道自动负载均衡与故障转移，核心调用可用性 ≥ 99.9% |
| 商业化 | 灵活、精确、可审计的计费与结算体系，支持个人/组织两类主体 |
| 可扩展 | 适配器插件化，新增厂商/模型可在不停机情况下接入 |
| 可管控 | 基于角色的模型授权矩阵 + 组织额度管控 |

## 目标用户

| 用户类型 | 描述 | 核心诉求 |
| --- | --- | --- |
| 独立开发者 | 个人调用多模型做应用/实验 | 一站式接入、按量付费、成本透明 |
| 创业团队 / 中小企业 | 多人共享额度、统一结算 | 组织钱包、成员额度管控、用量报表 |
| 中大型企业 | 内部 AI 中台、合规与审计 | 角色权限矩阵、审计日志、私有化/高可用 |
| 平台运营方（我方） | 运营该聚合平台 | 渠道/成本管理、利润倍率、运营数据 |

## 核心价值

- **统一接入**：一个 Key 调用全部厂商，OpenAI 兼容。
- **降本增效**：渠道成本管理 + 倍率定价，统一计费与成本可视。
- **高可用**：多渠道/多 Key 负载均衡与故障转移。
- **精细管控**：角色授权矩阵 + 个人/组织钱包与额度。
