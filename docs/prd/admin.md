## 运营数据（看板）

- 调用量、成功率、延迟分布。
- 上游成本 / 平台收入 / 利润。**收入口径只算现金支付部分**（`cash_charge_amount`），赠金消耗单列，见 [计费规则](./billing.md#赠送余额抵扣与收入口径)。
- Top 模型 / 用户 / 渠道。
- 渠道健康与熔断状态。

### 赠金看板（新增）

| 指标 | 说明 |
| --- | --- |
| 赠金余额敞口 | 全平台未消耗赠送余额合计（平台的潜在成本负债） |
| 当日发放 / 撤回 / 过期 | 按原因分类拆分，评估活动投放节奏 |
| 当日赠金消耗 | `Σ gift_charge_amount`，即营销费用的实际核销 |
| 赠金对应上游成本 | 赠金消费带来的真实现金支出，是投放的实际成本 |
| 赠金核销率 | 已消耗 / 已发放，衡量活动有效性与过期浪费 |
| 赠金转化率 | 领取赠金后**发生过现金消费**的用户占比，判断是否只在薅羊毛 |

## 关键规则

- 后台按管理角色做数据权限隔离。
- 所有写操作记审计日志。
- 敏感资源（渠道密钥、计费规则、调账、**赠送 / 撤回赠送**）仅超级管理员 / 财务角色可操作。
- 赠送操作额外受单笔上限与操作人日累计上限约束，超限拒绝并告警（见 [钱包与流水](./wallet.md#后台赠送操作)）。
