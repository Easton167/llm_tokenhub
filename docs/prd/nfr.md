# 非功能性需求

> 返回 [PRD 索引](../PRD.md)

---

## 性能与并发
- 网关层全异步（FastAPI + httpx async），I/O 不阻塞；上游连接复用连接池。
- 多进程部署（Gunicorn + Uvicorn workers），按 CPU 核数横向扩展，无状态服务可水平扩容。
- 流式转发零缓冲透传，首字节延迟（TTFT）≈ 上游延迟 + 网关开销（目标 < 50ms 网关开销）。
- 目标指标（需压测校准）：单实例并发连接 ≥ 2000，网关额外 P99 延迟 < 100ms。
- 热点数据（模型、计费规则、渠道路由表、权限）缓存到 Redis/本地内存，配置变更通过失效广播更新。

## 安全
- **凭证安全**：平台 API Key 仅存哈希；上游 Channel Key 应用层加密（AES-GCM，密钥由 KMS/环境隔离管理），前端脱敏展示。
- **传输安全**：全链路 HTTPS/TLS。
- **鉴权与会话**：前台 JWT（短期 access + refresh），API 调用 Bearer Key；敏感操作二次校验。
- **限流防滥用**：按 Key/用户/IP 多维限流（RPM/TPM/并发），异常流量告警。
- **越权防护**：模型授权、数据权限（用户仅见自身、组织仅见本组织）严格校验。
- **审计**：后台写操作与资金操作全量审计日志，不可篡改。
- **数据合规**：对话内容支持持久化正文。

## 可观测性
- **指标（Metrics）**：QPS、延迟分布、错误率、各渠道/Key 成功率与延迟、余额扣费成功率、上游成本/收入。Prometheus + Grafana 看板。
- **日志（Logging）**：结构化日志（request_id 串联），区分访问日志、错误日志、审计日志。
- **链路追踪（Tracing）**：OpenTelemetry 贯穿网关→路由→适配器→上游，定位慢调用。
- **告警**：渠道熔断、余额异常、错误率突增、对账差异触发告警。

## 可扩展性
- **适配器插件化**：新增厂商仅实现 `BaseAdapter` 并注册 Provider 类型，核心不改。
- **水平扩展**：服务无状态，状态外置（PostgreSQL/Redis）。
- **计费维度可扩展**：计费规则以配置驱动，新增维度（如图像张数、音频时长）通过规则字段扩展。
- **多区域/多租户**：预留租户隔离字段，二期支持。

## 可用性与容灾
- 多渠道/多 Key 故障转移；上游故障自动熔断与恢复。
- 数据库主从 + 定期备份；关键写操作幂等（request_id）。
- 对账兜底任务修复异常冻结/未结算记录。
