# 组织管理

> 模块 / 菜单：后台 · 组织管理；前台 · 我的组织  
> 返回 [PRD 索引](../PRD.md)

> 组织钱包扣费细节见 [钱包与流水](./wallet.md)；平台用户与模型授权角色见 [用户与权限](./users-permissions.md)。

---

## 功能点

- 创建组织、编辑组织信息、停用组织。
- 邀请 / 移除成员；设置组织内角色（Owner / Admin / Member）。
- 成员额度控制：
  - 「是否允许消费组织余额」开关。
  - 额度上限（总额度 / 周期额度，如每月上限；按**金额**计量，见决策 D2）。
  - 已消费额度累计与周期重置。
- 组织侧可见用量与费用分摊（按成员追溯发起人）。

## 组织角色

| 角色 | 职责 |
| --- | --- |
| Owner | 组织钱包充值、成员管理、额度分配、敏感资金操作 |
| Admin | 成员 / 额度管理（不含资金提现） |
| Member | 在配额内消费组织余额、调用模型 |

## 关键规则

- 以组织身份消费时，必须同时满足「组织钱包余额充足」与「成员剩余配额充足」，取更严格者。
- 组织扣费流水需记录「实际发起的成员用户」，便于成本分摊。
- 成员配额支持总额度或周期额度（如每月），周期到期自动重置。

## 边界与异常

- 成员不允许消费组织余额或额度不足：可按策略回退个人钱包，或直接 402 拒绝（见钱包模块）。
- 移除成员：不影响历史流水；未完成请求按原主体结算。
