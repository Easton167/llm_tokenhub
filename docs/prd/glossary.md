# 名词术语表

> 返回 [PRD 索引](../PRD.md)

---

| 术语 | 英文 / 标识 | 定义 |
| --- | --- | --- |
| 厂商 | Provider | 大模型供应商，如 OpenAI、Anthropic、阿里、DeepSeek。决定协议适配器类型。 |
| 渠道 | Channel | 一组指向某 Provider 的具体接入配置（Base URL + 一组 Key + 适配器类型 + 优先级/权重）。同一 Provider 可有多个渠道。 |
| 渠道密钥 | Channel Key | 渠道下的上游厂商 API Key，可配置多个，用于负载均衡/故障转移。 |
| 模型 | Model | 平台对外暴露的可调用模型逻辑实体，如 `gpt-4o`、`deepseek-chat`。 |
| 模型别名 | Model Alias | 平台对外的模型名（可与上游真实模型名不同），用于重命名、屏蔽厂商。 |
| 模型-渠道映射 | Model-Channel Map | 描述某模型可由哪些渠道提供，及在该渠道下的上游真实模型名。 |
| 适配器 | Adapter | 将「OpenAI 标准请求/响应」与某 Provider 的私有协议互相转换的组件。 |
| 用户 | User | 平台注册账号主体，可调用 API、管理个人钱包与 Key。 |
| 组织 | Organization (Org) | 多用户组成的团队/企业主体，拥有独立组织钱包。 |
| 组织成员 | Org Member | 用户在某组织内的成员身份，含角色与额度配置。 |
| 角色 | Role | 权限集合，核心用于绑定「可用模型」集合（授权矩阵）。 |
| API Key | API Key | 平台签发给用户/应用的调用凭证（区别于上游 Channel Key）。 |
| 钱包 | Wallet | 资金账户，分「个人钱包」与「组织钱包」两类，内含现金池与赠送池，记录余额与冻结额度。 |
| 余额 | Balance | 钱包**现金池**可用资金（用户充值 / 后台调账所得），可退款可提现。 |
| 赠送余额 | Gift Credit / Gift Balance | 平台无偿发放的余额，**不可退款、不可提现、不可转移**，有有效期，消费时优先扣减。 |
| 赠送批次 | Gift Grant | 一次赠送操作产生的账本记录，含金额、剩余、有效期、发放原因与操作人；扣减按到期时间 FIFO。 |
| 资金池 | Fund Pool | 钱包内的资金分区，含「赠送池」与「现金池」；扣减优先级为 赠送 → 现金 → 授信。 |
| 冻结额度 | Held / Frozen Amount | 请求受理时预扣（冻结）的资金，结算后释放并实扣；两个资金池分别记录冻结额。 |
| 计费规则 | Billing Rule | 某模型的定价配置（各 Token 单价、按次价、倍率、最小计费单位等）。 |
| 倍率 | Multiplier / Ratio | 在上游成本基础上的定价系数（含利润），如 1.2 倍。 |
| 预扣 | Pre-deduction / Hold | 请求开始前按预估用量冻结资金。 |
| 实扣 | Settlement / Capture | 请求结束后按实际用量结算并扣费，释放多余冻结。 |
| 用量日志 | Usage Log | 单次调用的 token 用量与费用明细记录。 |
| 流水 | Transaction | 钱包资金变动记录（充值、扣费、冻结、释放、退款）。 |
| 缓存命中 Token | Cached Token | 上游命中 prompt 缓存的输入 token，通常单价更低。 |
| 知识库 | Knowledge Base (KB) | 用户上传的私有资料集合，经解析、分块、向量化后可供检索问答。 |
| 分块 | Chunk | 文档切分后的最小检索单元，含内容、向量、启用状态，可人工编辑。 |
| 向量化 / 嵌入 | Embedding | 用 embedding 模型把文本转为向量的过程，是向量检索的基础。 |
| 向量检索 | Vector Search | 将问题向量与分块向量按相似度（cosine）比对，返回 Top-K 最相关分块。 |
| 检索增强生成 | RAG (Retrieval-Augmented Generation) | 先检索知识库相关内容注入提示词，再让模型基于其回答的问答模式。 |
| 命中测试 | Hit Testing | 用模拟问题验证知识库检索效果的调优工具，返回命中分块与相似度分数。 |
| 重排 | Rerank | 对初步召回的分块用重排模型二次排序以提升相关性（知识库后续增强）。 |
