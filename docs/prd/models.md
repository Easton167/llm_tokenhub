# 模型管理

> 模块 / 菜单：后台 · 模型管理  
> 返回 [PRD 索引](../PRD.md)

---

## 功能点

- 模型 CRUD：模型别名（对外名）、展示名、类型（chat/embedding/rerank/image 等）、能力标签（是否支持流式、函数调用、视觉、最大上下文）、状态。
- 模型-渠道映射：配置该模型可由哪些渠道提供，及每个渠道下的**上游真实模型名**（如对外 `gpt-4o` → 渠道 A 上游名 `gpt-4o-2024-11-20`）。
- 模型重命名 / 别名：对外名与上游名解耦，支持一个对外名映射多个渠道的不同上游名。
- 可见性配置：公开 / 仅授权角色可见；是否在前台模型列表展示。
- 默认参数与参数透传白名单：限制/默认 `temperature`、`max_tokens` 等。

## 关键规则

- 对外模型名全局唯一；映射关系决定路由候选渠道集合。
- `/v1/models` 接口仅返回「当前用户有权使用且可见」的模型。
- 同一对外模型映射多渠道时，结合[渠道管理](./channels.md)路由策略选择具体渠道与上游名。

## 边界与异常

- 模型未映射任何启用渠道：对外标记不可用，调用返回 503/400。
- 删除模型：若存在历史用量/计费规则，做软删除（禁用）而非物理删除，保留审计。
